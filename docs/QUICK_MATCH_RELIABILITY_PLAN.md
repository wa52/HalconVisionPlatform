# 快捷匹配可靠性四轮计划

| 轮次 | 状态 | 交付与验收边界 |
| --- | --- | --- |
| 1 候选与可靠性 | 已实施，本机限定范围通过 | 多候选、独立判定、原始/可信结果、原因/耗时，拒绝阻断位置矫正；真实HALCON/合成控制图及官方PCB回归，尚非真实产线准确率验收 |
| 2 模板质量 | 待实施 | 边缘数量/长度与分布、重复/对称风险、背景干扰、明确原点示教及模型身份；用有问题的模板验证可解释建议 |
| 3 参数评估 | 待实施 | 用户带真实位姿标注的调参集；确定性参数搜索与版本化报告；独立测试集不参与选参，统计误接受、漏检、位置/角度误差和耗时 |
| 4 长期运行 | 待实施 | 8小时实测，记录内存/句柄/P50/P95延迟、停止恢复、异常输入与项目切换；再按产线要求加长 |

每轮保留真实验收与未完成项，更新说明并提交GitHub。第一轮实现与证据见 [节点说明](QUICK_MATCH_NODE.md)、[本轮验收](evidence/2026-10-20-quick-match-reliability.md)。没有真实产品标注集时，只能证明控制图上的算法/链路行为，不能报告产线准确性。
