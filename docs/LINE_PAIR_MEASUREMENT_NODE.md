# 线线测量

类型 `halcon.line-pair-measure`。将同一帧原图连接到两次直线查找与本节点，两条 `line` 分别连接 `lineA` / `lineB`。公差在检测任务中配置。

## 量的定义

| 输出 | 定义 |
|---|---|
| `angle` | 无方向小夹角 0～90°，HALCON `angle_ll` 结果归一化；反转端点不会改变角度 |
| `segmentDistance` | HALCON `distance_ss` 的两条**有限线段**最短距离，像素单位 |
| `measurement` | 两条完整线段、小夹角、最短距离、分别位于两条线段上的最近点 |
| `overlay` / `preview` | 可组合图形与独立 RGB 预览，不修改原图 |
| `status` | `LINE_PAIR_MEASURED` / `LINE_PAIR_MISSING` |

线段相交或共线重叠时距离为 0，不画假长度连接线；只有延长线相交、有限线段不相交时，距离可以大于 0。该节点不输出无限直线距离、方向角、平均间距或毫米值。

直线查找的拟合线段端点来自搜索范围，因此修改 ROI 长度可能改变最近距离。平行间距检测建议同时配置距离范围和接近 0° 的夹角范围，不能仅凭一个最短距离推断两线平行。

## 显示及判定

两个属性开关为“显示拟合线段”和“显示最短距离连线”。A 线绿色、B 线青色，最短连接线黄色；可在同图组合角度、距离、其他节点和任务判定。标注保留三位小数，完整输出与闭区间公差比较使用原精度。

检测任务新增数值规则默认选择 `segmentDistance`；可再添加 `angle` 范围。测量执行成功不等于产品 OK。正常测量超差为 NG，必检几何缺失、空值、错误为 ERROR。

## 保护与限制

两条线必须为本轮同帧、同坐标空间的有效线段，原图必须是未标注单幅图。拒绝重合端点形成的退化线、非法/越界坐标、无来源和跨帧几何。整个包围矩形必须位于有效图像域和绑定任务范围，属于保守检查，不会裁掉无效部分后继续放行。

缺失输出为空，不复用旧 JSON、旧图形或零值。原生距离与绘图端点距离不一致时拒绝结果。预览和 HALCON 临时对象按执行所有权释放。

本轮仅完成合成样本、短时运行和资源生命周期验证；真实标准件误差、标定、现场相机和长期稳定性仍需验收。
