# 深度学习会话缓存：流程与生命周期

## 变更前基线 · 2026-10-16

真实组合流程（分割与分类各两个重叠 ROI）：首次 77.68 秒，后两轮 2.10 / 2.74 秒。裁剪、独立掩膜域、分类映射、保存恢复、失败输出释放等 51 项断言通过。此数据来自命令行真实模型测试，不含 UI 绘制。

## 实施约定

工作区独立拥有 DlModelSessionCache，由两个深度学习执行器借用。默认最多保留两个模型，可通过构造容量配置；使用独占租约防止同一个会话被并行调用或在推理中被释放。没有传入缓存的独立执行器仍使用每轮加载和释放模式，方便直接对照。

2026-10-22 起按模型包身份共享，不再按节点标识缓存。同一模型目录、任务、实际模型类型、设备及模型包五个文件的长度/修改时间共同参与身份判断。默认 GPU / 索引 0 与显式相同配置使用同一身份；同模型的 P1–P6 六个节点仅占一个缓存项。容量满时淘汰最久未使用的模型身份，而非最久未使用的节点。`ModelLoads` 累计成功加载次数，清空缓存不重置该诊断计数。

首次加载或身份变化时执行完整模型包校验；命中时检查文件元数据。不能检测人为保持长度和修改时间不变的替换，因此模型包应视为运行期间不可变的版本目录。变化后的版本形成新身份，旧身份可保留至容量淘汰或清空。加载期间再次检查身份，拒绝变化中的包。

ROI、期望类别和检测阈值不进入缓存身份。目标检测执行器在每次独占租约内重新设置置信度、NMS、类别间抑制和最大目标数，再执行本节点推理；不同节点的参数不得互相污染。真实检查包括 P1 阈值设为 1 后单独 NG，而 P2–P6 保持 OK。当前独占门覆盖整个缓存，串行执行，不承诺多模型并发吞吐。

首次真实 ROI 推理承担预热，首轮耗时单独记录；不生成虚构输入，不把首轮耗时与后续缓存命中耗时混算。每个 ROI 的样本、预测、裁剪及中间结果仍立即释放；本轮输出归 WorkflowExecutionRun。取消或异常后的会话不放回缓存。成功租约归还后会话仅供后续轮次复用，不持有本轮图像。

2026-10-22 性能优化：每个 `DlInferenceSession` 同时拥有一个官方 `preprocess_dl_samples` 过程及 HDevEngine，随模型缓存一起复用、淘汰和释放。每次预处理仍创建并释放独立 HDevProcedureCall、样本参数元组，不缓存带图像的调用实例。构造、调用及释放沿用过程锁；调用前后检查取消，已释放的过程拒绝复用。初始化失败会清理已创建的资源，保留原始与清理错误。HALCON 官方过程目录在模型会话建立时固定，更新运行环境应重启软件，不支持运行中热替换官方过程。

同机六 ROI 的 24 次 real 张量逐字节一致；热预处理中位数从 209.34 ms 降至 1.24 ms，加载过程约 1.15 秒转移至会话建立时。完整九节点链路两组各 60 轮，相同 12 个采样轮次的均值从 1746 ms 降至 460 ms；并非核心神经网络单次推理耗时。进程内存区间仍相近，清空模型后未完全归还操作系统，不能宣称此改动降低了全部保留内存或解决长期泄漏。见 [性能与生命周期实测](evidence/2026-10-22-preprocessing-performance.md)。

停止连续运行、切换项目、关闭项目和退出时等待执行者结束，再清空缓存。模型或设备参数变化在下次执行时使用新身份。异常或取消的租约淘汰其共享会话，下一请求重新加载。停止后保留末轮结果供查看；切换项目及工作区关闭释放末轮输出。缓存不拥有输出。不能抢占运行中的 HALCON 原生算子；停止响应取决于当前算子完成时间。

## 验收范围

同一可重复命令记录无缓存/缓存版本的时延、进程内存和原生输出释放；另验证同模型命中、参数/文件变化失效、清空后重载、取消后重建、关闭后拒绝获取。真实窗口交互与长时间 GPU 显存增长需要分别记录，不以短测试替代现场长期验收。

2026-10-22：P1–P6 同模型六分支真实链路 1219 项、跨模型 LRU / 文件变更及清空重载 39 项通过。30 轮检查验证输出释放及会话数量上限；进程私有内存仍有高水位增长，不能据此宣称无泄漏或已完成 8 小时稳定性验收。见 [本轮记录](evidence/2026-10-22-p1p6-inspection-tasks.md)。
