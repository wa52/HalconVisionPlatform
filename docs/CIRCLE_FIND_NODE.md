# 圆查找节点

`halcon.circle-find`，位于“特征检测”。使用 HALCON 24.11 的 2D Metrology，在参考圆附近采集边缘并拟合一个完整圆。

## 使用

1. 将“读取图像”或相机的**原始图像**连接到圆查找的 `image`；带标注的预览不能作为输入。
2. 选中圆查找，用属性里的绘制图标框住完整圆。搜索框中心就是参考圆心，框中保留径向搜索和卡尺所需的余量。
3. 参考半径填像素值；0 表示按框尺寸估计。调整径向搜索半宽、边缘阈值、从圆内向外的边缘极性和最小拟合评分，再单次运行。
4. 找到时显示绿色完整拟合圆和圆心；未找到时显示红色搜索框，明确提示原因，圆和直径为空。
5. 在检测显示配置中选择直径、评分及图形；圆心、半径、周长、径向残差和全部边缘点仍可在节点输出中查看和供后续开发计算使用。

如果节点属于独立检测任务，“矩形搜索范围”会标为“任务区域”。绘制会编辑实际生效的命名任务区域，共用该区域的任务同步变化；节点中不能清空任务区域。任务编辑器新增圆查找规则时默认检查 `status` 的 `/Code` 等于 `CIRCLE_FOUND`，仍须保存有效的任务与规则配置，不能把算法执行成功当成产品 OK。

## 参数

| 分组 | 参数及初值 |
|---|---|
| 基本 6 项 | 矩形范围、参考半径 0、径向搜索半宽 10 px、边缘阈值 20、边缘极性 all、最小评分 0.6 |
| 高级 9 项，默认折叠 | 卡尺数量 48、切向半长 3 px、平滑 σ 1、结果半径范围 1～100000 px、最大径向残差 2 px、显示搜索框/拟合圆开、诊断显示关 |

参考圆及卡尺必须完整放在搜索框内。范围过小、越界、无效像素、参数非法时明确报错。评分是 HALCON 使用边缘比例相关的拟合评分，不是概率意义上的置信度。径向残差是实际参与拟合的边缘点到拟合圆的 RMS 距离，单位 px。

## 输出契约

| 端口 | 类型 | 含义 |
|---|---|---|
| circle | halcon.circle2d | `Row`、`Column`、`Radius`；派生 `Diameter`、`Circumference`，输入图像行列坐标，像素单位 |
| diameter | number | 直径，未通过拟合校验时为 null |
| score / residualRms | number | 实际评分及径向残差；未有候选时为 null，候选被拒绝时保留诊断值 |
| edgePoints | halcon.point-set | HALCON 实际用于拟合的边缘点，映射回输入图坐标 |
| count | number | 0 或 1 |
| status | inspection.result | `CIRCLE_FOUND` / `CIRCLE_NOT_FOUND` 和说明 |
| overlay | halcon.geometry | 搜索框、圆、边缘点、可选卡尺及显示开关 |
| preview | halcon.image | 输入图大小的私有彩色预览，明确标记为已标注图像 |

没有候选、评分不足、半径/偏移/范围或残差校验失败均不输出假圆或旧圆。异常和取消由流程引擎传播为 ERROR/取消，不作为正常未找到。未配置统一任务时不输出产品合格结论。

## 实现与边界

- 创建测量模型 → 添加圆测量对象 → 设置参数 → apply → 读取圆参数、评分和实际使用的边缘点 → 释放模型。预览使用私有物理通道副本，上游像素不被修改。
- 官方 `apply_metrology_model` 忽略 reduced domain，因此先检查有效像素并实际裁剪矩形，再进行测量，而不是仅缩小 domain。结果平移回输入坐标，矫正图仍遵守有效区域约束。
- 单节点查找参考圆附近的**一个完整圆**，不是全图自动寻找所有圆、椭圆或圆弧。一个输入必须是一张图像；文件夹可由读取节点逐帧执行。
- 暂无像素到毫米标定及圆圆/线圆测量节点；`halcon.circle2d` 已提供可扩展的几何数据契约，但不意味着这些下游算法已经实现。
- HALCON 原生 apply 调用内不支持强制中断；取消在调用前后检查，完整退出后释放对象。本次短时启停通过不等于 8 小时稳定性或真实标准件精度验收。
