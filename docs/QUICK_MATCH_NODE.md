# 快捷匹配节点

节点类型 `halcon.quick-match`，位于节点库“定位匹配”。使用 HALCON 24.11 的形状模板匹配，定位平移和旋转的目标。首版不支持缩放、形变、多个不同模板或多搜索 ROI。

## 配置步骤

1. 连接“读取图像/相机采集 → 快捷匹配”的 Image 端口。
2. 在节点属性中选择一张模板图像。也可点击相机图标“取当前图像为模板”，将输入保存为新的 PNG；相机及处理节点需先运行产生图像，文件读取源可直接取第一张。模板保存后会清空旧模板范围。
3. 点击“模板范围”旁的绘制图标，在显示的**模板图像**上拖出矩形。空范围使用整幅模板；尽量只框住稳定、有区分度的目标边缘。
4. 可点击“搜索范围”旁的绘制图标，在**输入图像**上框选搜索区域。空范围搜索全图。绘制结束保留金色矩形，运行后金色边框表示搜索区域，绿色轮廓表示实际匹配结果。
5. 设置最低评分、最多匹配数和角度范围，单次运行检查；文件夹逐图或相机流程可连续运行。
6. 保存 `.hvproj`。模板文件路径、两个矩形及全部参数随项目保存；图片本身不嵌入项目，移动工程时需保留文件或重新选择。

两种矩形均使用原图行列坐标，越界部分裁到图像内，完全在图外时报错。搜索 ROI 限制 HALCON 模板参考点的搜索位置，**不保证整个目标轮廓都位于矩形内**。绘制完成不代表已经匹配，需重新执行。

## 参数

| 参数 | 默认值 / 范围 | 含义 |
| --- | --- | --- |
| 最低匹配评分 | 0.6；0 < 值 ≤ 1 | HALCON 形状匹配评分阈值，不是概率置信度 |
| 最多匹配数 | 1；1–100 整数 | 单张图像最多返回的目标数 |
| 起始角度 / 角度范围 | −180° / 360° | 起点 −180…180°，范围 0…360°，两者之和不超过 180° |
| 最大重叠 | 0.5；0–1 | HALCON 的重叠抑制条件 |
| 搜索贪婪度 | 0.8；0–1 | 提高可能更快，但也可能漏检 |
| 建模边缘对比度 / 最小对比度 | 30 / 10；1–255 整数 | 建模和搜索的边缘条件 |
| 忽略整体明暗反转 | 否 | 启用 `ignore_global_polarity`，否则 `use_polarity` |
| 单图搜索超时 | 5000ms；1–60000 整数 | HALCON `find_shape_model` 的超时限制 |

低纹理、模板包含大量背景、遮挡、亮度或尺度变化都可能影响匹配。评分和阈值需要用真实产品的正负样本验收。

## 输出与显示

| 端口 | 内容 |
| --- | --- |
| preview | 与输入尺寸一致的 RGB 结果图；绿色匹配轮廓、金色搜索边框 |
| matches | 单图的匹配数组，包含 Row、Column、AngleDegrees、Score |
| imageResults | 每张输入图像的 ImageIndex（从 1 开始）和 Matches |
| row / column / angle / score | 单图最高评分匹配的参考点坐标、角度（度）和评分 |
| count | 本次输入所有图像的匹配总数 |
| status | MATCH_FOUND / MATCH_NOT_FOUND / MATCH_PARTIAL 及说明 |
| overlay | 检测模式的受管几何数据；JSON 只记录数量摘要 |
| modelInfo | 算法方式、模板路径、本轮是否命中缓存 |

Row/Column 是 HALCON **模板模型原点（默认模板区域重心）在原图中的位置**，不是对象任意定义的中心；修改模板范围可能改变原点。AngleDegrees 使用 HALCON 行列坐标及旋转约定。后续计算使用 `matches` / `imageResults` 的数值，不能把预览像素当作几何结果。

未找到时 matches 为空、count 为 0、标量坐标/评分为 null，红色显示“未找到模板目标”。执行成功只表示算子执行完成。部分批量图像找到时为 MATCH_PARTIAL；原生批量输入要求尺寸一致，此时单图 matches 为空，标量为 null，应使用 imageResults。文件夹在工作台中按每轮一张执行。

检测模式可将本节点的几何轮廓与共同图像来源、相同尺寸的其他节点结果组合；可选参考点行列、角度、评分和数量。参数配置仅在编辑模式的节点属性内。

## 生命周期

工作区拥有最多 4 个缓存模型，按节点、模板文件 SHA256、模板 ROI、对比度及极性设置识别；调整搜索范围/阈值不会重建模型。访问由独占租约串行保护，错误或取消的执行会移除本轮模型；停止、切换项目和关闭时清理。独立执行器未注入缓存时在每次执行结束释放模型。

每轮图像由执行结果持有，下一轮替换或结果销毁时释放；叠加数据为受管坐标，无外泄的 native 句柄。释放模型不使已保留的结果预览失效。

取消在算子边界生效；正在创建模型或执行 HALCON 同步算子时需等待返回。搜索超时不约束建模耗时，也不是严格的 UI 停止时限。模板内容每轮读取摘要，较大的模板文件存在 I/O 成本。
