# 位置矫正节点

实现日期：2026-10-19。节点类型 `halcon.position-correction`，位于节点库“定位匹配”。

## 用途与连接

利用快捷匹配得到的唯一位姿，把平移、旋转后的产品图像对齐到示教位置。下游在矫正图上使用固定 ROI。

```text
读取图像 / 相机 ── image ──────────────────┐
       └── image → 快捷匹配 ── poses ──────┤
                                          ▼
                                      位置矫正
                                          │ image
                              二值化 / 直线 / DL 多 ROI
```

两条输入必须来自本轮同一帧、同一坐标空间。连接匹配节点的 `poses`，并把未绘制标注的原始图像接到矫正节点的 `image`；匹配预览不能作为算法原图。

2026-10-21：原图输入声明 `RequiresUnannotatedImage` 端口约束。已知带标注的输出（例如快捷匹配 `preview`）在连线时直接拒绝，并给出原图连接提示；打开已有错误连线的项目时也会列出具体校验问题，不静默改写连线。此静态检查只覆盖输出端口明确声明的标注属性，运行时仍核对帧、坐标空间与实际标注来源，透传链路不能靠静态检查代替运行时保护。

## 示教步骤

1. 放入标准产品图，配置快捷匹配的模板和搜索范围，使其只找到一个目标。
2. 按上图连接并单次运行。首次出现 `REFERENCE_REQUIRED` 是尚未示教；上游匹配结果仍保留。
3. 选中位置矫正，在右侧“示教基准”点击 **设为基准**。该操作先停止执行，再核对上次结果、当前配置和模板内容；过期结果不能示教。
4. 重新单次运行，选择位置矫正查看矫正图。把下游检测节点连接到它的 `image`，在这幅基准坐标图上确认 P1～P6 等固定 ROI。
5. 保存 `.hvproj`，再用偏移、旋转图检查。连续运行不会自动改变基准。

“清除基准”在同一属性区域。操作提供中文说明并沿用全局 1500ms 提示规则。示教位置、尺寸和时间保留文字，检测模式不增加示教或阈值控件。

模板内容、建模参数、模板范围或输入链配置改变后，需要重新示教。输入尺寸改变会报错；同尺寸换物理相机或视野也需要人工重新示教，软件不能仅凭尺寸识别这种变化。

## 参数与输出

参数包括示教基准、启用位移与旋转限制、最大位移和最大旋转。限制默认关闭；开启后按位姿相对于基准的欧氏位移及归一化角度差判断。参数随项目保存。

| 输出 | 内容 |
| --- | --- |
| `image` | 基准尺寸的矫正图，独立对象，同时用于节点图像显示 |
| `transform` | 当前→基准、基准→当前两组矩阵，以及两端空间身份 |
| `offsets` | 当前/基准位姿、行列差、角度差和匹配评分 |
| `validRegion` | 矫正后仍有有效输入像素的 HALCON 区域 |
| `status` | 正常完成返回 `CORRECTION_OK`；异常走执行错误通道 |

矩阵是长度 6 的 HALCON 仿射矩阵数组 `M=[m0,m1,m2,m3,m4,m5]`。在 `pixel-center-row-column-v1` 约定下，`row'=m0*row+m1*column+m2`、`column'=m3*row+m4*column+m5`。调用方可使用 HALCON `affine_trans_point_2d` 或等价矩阵计算。角度数据用度，调用 HALCON 时转为弧度。

行列差是“当前位姿减基准位姿”，不是含旋转时矩阵中的平移项。高级坐标和矩阵仍完整输出，可供后续计算。图像重采样的半像素适配集中在 `PositionTransform.ForPixels`，消费标准几何矩阵时不要再次补偿半像素。

## 有效区域与显示

使用 HALCON 刚性变换及固定画布双线性重采样；输出保持 byte 灰度/RGB 类型。输入 domain 同步变换、与基准画布求交，作为输出 domain 和 `validRegion`。

旋转或平移可能产生缺失角落。分类、分割、目标检测和直线节点在处理前检查矫正图 ROI：任何启用 ROI 越界或含缺失像素，报 `ROI_OUTSIDE_VALID_IMAGE`，不会自动裁小或加载模型推理。全图检测也适用，应改用有效区域内的 ROI。二值化保留 domain，Blob 跟随输入区域。

检测面板允许矫正图组合其下游结果；原图和矫正图属于不同坐标空间，不能直接混叠。当前不自动把下游结果回投原图，反向矩阵已提供给后续扩展。

## 错误与资源

常见错误：`REFERENCE_REQUIRED` 未示教、`REFERENCE_STALE` 配置变化、`POSE_NOT_FOUND` 无匹配、`POSE_AMBIGUOUS` 多匹配、`FRAME_MISMATCH` 帧不一致、`ANNOTATED_IMAGE` 使用标注图、`POSE_OUT_OF_RANGE` 超限。失败不产生替代图像或旧矩阵，下游跳过。

每轮只接受单幅图像，文件夹通过现有调度逐张执行；不默认选取原生多图元组中的第一张。仅支持单产品刚性平移/旋转；缩放、透视、多目标逐件矫正和自动回投未实现。

上游图像只借用；临时图像、区域、HTuple 在异常和取消路径清理，输出由本轮运行集中释放。停止等待同步 HALCON 算子返回，不能承诺立即打断原生调用。项目切换、关闭和重新运行释放旧结果。
