# 圆圆测量

节点类型：`halcon.circle-pair-measure`。单位为输入图像像素，尚未包含毫米标定。

## 接线与使用

1. 将同一读图或相机节点的原图连接到两个圆查找节点及圆圆测量的原始图像输入。
2. 两个圆查找的“圆几何”分别连接“圆 A”和“圆 B”。不要连接带标注的预览图。
3. 运行后查看圆心距、圆周最短距离、完整测量数据和状态；检测显示可在原图上组合测量图形及数值。
4. 需要产品合格判定时，在检测任务中为 `centerDistance`、`boundaryDistance` 配置数值范围。上下限含边界，使用原始精度比较。

两个显示开关控制圆心连线及圆周最短连线。圆轮廓为绿色，圆心连线为青色，圆周最短线为黄色；相交、相切或重合时最短距离为零，不绘制虚假的零长度线。

## 输出

| 端口 | 内容 |
|---|---|
| `centerDistance` | HALCON `distance_pp` 计算的圆心距 |
| `boundaryDistance` | 解析圆周最短距离，相交为 0，包含时为内间隙 |
| `measurement` | 两圆完整坐标、距离、关系、圆心线及可空的最短线段 |
| `overlay` | 可组合显示的托管几何数据 |
| `preview` | 独立 RGB 标注副本，不修改上游图像 |
| `status` | `CIRCLE_PAIR_MEASURED` 或 `CIRCLE_PAIR_MISSING` |

圆周距离公式为 `max(0, d-rA-rB, abs(rA-rB)-d)`，其中 d 为圆心距。它测量的是两圆周的距离，不是两个实心区域的距离。

## 安全和资源边界

- 圆与原图必须来自当前轮次的同一帧和同一坐标空间；不同采集即使读取同一个文件也不能混用。
- 缺圆时返回空测量值，不用零值冒充成功。算法完成不等于产品 OK，必检任务缺少可信结果时为 ERROR。
- 圆必须完整位于图像、有效域和绑定的测量任务区域中。当前采用保守的完整包围矩形检查，不对越界圆自动裁切。
- 图像文字显示最多三位小数，结构化输出保留完整精度，供后续计算和判定。
- 运行结果拥有预览图像；重跑、停止、项目切换和关闭按工作区生命周期释放。

专项检查使用程序生成的已知尺寸图像，不替代标准件精度、相机标定及现场长期稳定性验收。
