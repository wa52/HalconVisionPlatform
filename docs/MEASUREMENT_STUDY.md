# 标准件测量验证

入口：**项目 → 测量验证**。该窗口记录当前流程的长度测量，不修改算法、标定或产品公差。只保留一个窗口，打开时仍可在主窗口运行下一轮。

## 使用

1. 先配置直线、圆或距离测量；如需毫米，接入比例标定与长度换算。
2. 选择声明为 `px` 或 `mm` 的标量长度输出。角度、面积、评分、数量及未知单位不列入。
3. 填写标准件名称和参考值，单位必须与字段一致。有符号净距可使用负参考值。
4. 填写采样位置/样本编号，在主窗口完成单次运行，点击 **记录当前测量**。连续运行时先停止再记录。
5. 首次记录后锁定字段、参考值和流程配置。重新取像运行，再记录下一轮。同一 RunId 不重复收录。
6. 用导出图标保存 **JSON 或 CSV**。新建、关闭尚未导出的记录会提示；记录不自动写入 `.hvproj`，暂不支持导入报告继续追加。

每组最多 10,000 条。图像来源节点、尺寸、空间模式或流程/标定参数改变后须新建验证，避免混入不同条件；结果过期或跨流程不收录。算法完成但没有长度、节点跳过/失败、流程异常和缺有效单帧来源会记录为失测，不用 0 替代。

## 统计含义

| 字段 | 含义 |
|---|---|
| 总数 / 有效 / 失测 | 记录轮次及其中可用于统计的数值数目 |
| 均值 | 有效测量值平均值 |
| 偏差 | 均值 − 参考值，保留方向 |
| 标准差 | 样本标准差，分母 `n−1`；不足两个有效值显示 `—` |
| 极差 | 最大有效值 − 最小有效值 |
| 最大绝对误差 | 所有有效值中最大的 `abs(测量值−参考值)` |

无有效值时数值统计为空；真实零值仍有效。显示保留 9 位有效数字，导出保持 double 原始精度。统计溢出不提交当前样本。

JSON 包含冻结的流程配置、配置身份、参考值、统计、逐轮 RunId/时间/帧来源/图像文件和失测原因；它是完整报告，不是可执行项目。CSV 使用 UTF-8 BOM、固定小数格式，含汇总和逐轮数据；文本引号/换行转义，文本标识防止被表格软件解释为公式。保存先写同目录临时文件再替换，失败保留窗口记录。报告只允许 `.json`/`.csv`。

## 计量边界

本功能提供数据收集和统计，不自动宣布标定合格。同一张图片反复计算不能代替真实重复取像。应使用已知实际尺寸的标准件，在视场不同位置、方向和重复取像条件下记录；参考量具不确定度、跨日期/人员、重装和 MSA 需要另行评估。

合成检查中的 15 mm 是软件演算结果，不能作为本机相机的实际标定或产线精度证据。成像条件变化后重新标定，不能仅凭分辨率相同沿用比例。
