# 等比例标定与长度换算

首版用于固定相机、镜头、工作距离、同一物平面且横纵等比例的**原始图像**。使用已知标准件长度与其像素长度求 `mmPerPixel = 实际毫米长度 / 像素长度`。这不是棋盘格相机标定，不补偿镜头畸变、透视或非等比例缩放；首版拒绝已矫正的图像空间。

## 配置步骤

1. 在相同成像条件下采集已知实际长度的标准件。先用现有找线、线线距离等工具读取对应的像素长度；参考的是标准件的真实尺寸边界，不能用任意 ROI 长度代替。
2. 添加“比例标定”，接未缩放原图，填写标准件像素长度、实际长度（mm）、参考图像宽/高。参考像素长度必须是图内直线距离，不大于图像对角线。
3. 确认同相机/镜头/工作距离、同物平面及等比例条件，再勾选确认。默认数值为 0、确认关闭，未配置不会产生可用标定。
4. 添加“长度换算”，连接比例标定的 `calibration`，并将测量节点的像素长度端口连接到 `pixels`。
5. 待测图必须来自本轮同一图像来源及空间。生产图片可逐张切换，保存的参考长度和比例不从当前产品重新学习。
6. 在同一检测任务中包含上游测量和换算节点，用 `lengthMm` 设置毫米公差。上下限包含边界，按原始 double 比较。保存 `.hvproj` 后恢复参考参数、确认状态、接线与毫米规则。

## 支持的长度

可直接连接：直线查找长度、圆查找直径及径向残差、圆圆距离、线圆距离/有符号净距、线线有限线段距离。正数、真实零距离和负净距保持符号进行换算。

角度、评分、面积、数量和未声明单位的透传输出不能连接到像素长度输入；`mm` 或 `mm/px` 也不能当作 `px` 二次换算。已有像素端口 ID 和 `number` 类型保持不变，仅补充单位声明；旧方案无需重建接线。

## 输出与显示

| 节点 | 输出 |
|---|---|
| 比例标定 | `calibration`（原始参考值、mm/px、宽高、条件确认和方法）、`mmPerPixel`、`status` |
| 长度换算 | `lengthMm`、`result`（像素值、毫米值、完整标定与单位）、`status` |

图像可继续显示上游像素图形，同时组合毫米数值及产品判定。换算不会缩放图像、改动上游像素结果或创建重复预览。常用数据有明确 mm/mm·px⁻¹ 标签；完整精度留在节点输出。很小的非零值采用科学记数，避免显示为假零。

标定参数和图像尺寸不一致、未确认、跨帧、溢出/下溢等拒绝结果。上游未找到几何时，毫米值为空，必检任务为 ERROR；正常换算超出毫米公差为 NG。已完成换算不等于产品 OK。

## 必须了解的范围

当前无法自动发现**相同分辨率下**的镜头、变焦、工作距离或物平面变化。条件变化必须取消确认并重新标定；尺寸相同不证明比例仍有效。单一比例也不能证明全视场精度，应使用独立标准件、不同位置/方向及重复采集评估误差。

示例工程中的 100 px 对应 10 mm 仅为合成图的软件演算参数，不是本机相机的真实标定。未提供标准件图片与实测尺寸时，不能据此把实际产品尺寸视为已校准。
