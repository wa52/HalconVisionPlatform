# UI 重复功能入口检查（2026-10-19）

## 范围

检查主窗口按钮和菜单的命令入口，保持图标操作和 1.5 秒功能提示。

## 调整

- 文件新建、打开和保存集中于“文件”菜单，移除顶部重复按钮。
- 流程新建、导入和导出集中于“项目”菜单，移除画布标题处重复按钮。
- 单次运行、连续运行和停止保留顶部入口，移除重复运行菜单。
- 节点添加、复制、粘贴、删除、撤销和重做集中于流程工具栏，移除重复编辑菜单与顶部撤销/重做。
- 适应画布移至流程工具栏，与画布缩放放在一起。
- 原有快捷键和节点库双击添加继续可用。

## 检查结果

通过 XML 解析收集 MainWindow.xaml 的全部 36 个 Click 绑定，并按处理器分组。调整后每个命令处理器只绑定一个可视入口，例外是 PickImage_Click：选文件与选文件夹是两个不同操作，使用同一处理器根据按钮内容区分。原来有 11 组同命令重复入口，其中撤销/重做各出现 3 次，其余各出现 2 次，现均合并。

独立图像窗口、画布、节点图像与检测配置中的缩放服务于不同视图；多 ROI 编辑和单 ROI 参数按节点条件显示，保留各自操作。

实际打开发布版和 P1–P6 项目，查看主窗口并切换检测模式、返回编辑：顶部只有一组运行控件，检测模式隐藏节点工具栏，返回编辑后工具栏恢复。

Release 构建成功：0 个警告、0 个错误。本次检查针对界面入口、模式切换和构建，不重新执行模型推理或相机采集。
