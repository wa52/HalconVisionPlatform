# 单个面板组合多个节点内容

纠正上一轮只允许每个面板绑定一个节点的结构。现在一个 DetectionTile 持有多项 DetectionContentSettings，每项可以独立指定节点、图像/输出参数/检测结果和具体字段。

- 面板顶部“添加内容”在当前面板增加一个内容项；“移除内容”只移除该项，“删除面板”才删除整个组合。
- 旧面板记录没有 Contents 时迁移为一个内容项，保留原来的来源与显示选择。
- 新项目默认一个面板，内部组合读取图像、处理图像、参数与结果；各项来源独立。
- 保存项目恢复全部内容项；复制/导入流程同时重映射内部内容项的节点 ID。
- 各内容项拥有独立图像控制器，在移除内容、删除面板、切换项目和关闭时释放，不持有执行图像引用。

验证：Release 0 警告/0 错误，1900 WPF 路径退出 0，确认仅一个父面板同时持有 4 个内容项且包含 2 个节点来源，字段选择独立，添加/移除内容不改变父面板数量，保存/重新打开恢复嵌套组合，原图像与轮廓释放断言通过。

本地证据：`artifacts/composite-panel-final`；发布：`artifacts/desktop-composite-panel`。用户原项目文件不写入测试配置。
