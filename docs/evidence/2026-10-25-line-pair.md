# 线线距离与夹角验收

起点 `0434354`。只修改 HalconVisionPlatform；原始方案、模型、图像、HALCON 安装和许可证保持不变。

## 本轮完成

- 新节点 `halcon.line-pair-measure`：同帧原图和两条拟合线输入，HALCON `distance_ss` 计算有限线段最短距离，`angle_ll` 归一化为 0～90°无方向小夹角。本机 HALCON 24.11 官方算子文档已核对。
- 输出距离、角度、完整线段及最近点、叠加、独立预览与明确测量/失测状态。最近点连线距离与 HALCON 数值不一致则拒绝输出。
- 两项绘图开关；复用任务数值公差、同图组合显示、完整数据、帧身份和资源所有权，未新增重复运行或判定入口。
- 缺少直线输出空值，错帧、非法几何、无效域、超出任务区域拒绝执行；算法成功不等于产品合格。

有限线段、反向端点及 ROI 长度对距离的影响见[使用说明](../LINE_PAIR_MEASUREMENT_NODE.md)。

## 视觉审查和未覆盖项

七项自评均为 4/5：协调性（沿用原主题）、层次（角度/距离/任务状态）、排版（短标注与完整数据）、组件（共享图标、1500 ms 提示和开关）、空间（紧凑节点和两项属性）、交互（空图明确失测）、完成度（输入输出及真实窗口证据）。内容布局覆盖最小和常用宽度，截图为当前常用窗口；多 DPI、触摸、多显示器和全部弹窗未验收。

未实现毫米标定、平均间距和有方向角度，也未完成标准件误差、真实相机/PLC、8 小时或现场验收。原间歇原生启动异常根因仍未确认，本轮成功不代表已修复。

实际正常/空图交替连续运行超过 58 秒，停止后能再次启动，并在运行中关闭。自动化输入发生缓存失效时先重新观察，再完成操作；未把失败输入当作产品崩溃或成功停止。

本轮窗口已确认退出，其他项目/发布路径的用户窗口保留。已备份到 artifacts/line-pair-desktop-backup-20261025 并同步原桌面路径；[六项发布文件哈希一致](line-pair-20261025/install-hashes.json)。软件与快捷方式名称保持不变；未重复手工双击快捷方式，方案启动与恢复由真实窗口及生命周期检查覆盖。
