# UI 与运行生命周期验收（2026-10-12）

## 问题与修复

原连续执行循环中，HALCON 执行器返回同步完成的 ValueTask；await 未让出 UI 线程，循环持续占用 Dispatcher。原回归检查在两秒内只得到 2 次 UI 心跳，判定未响应。

修复后，流程算子在后台执行，连续循环每轮让出 UI，日志保留最近 500 条，并防止重复启动。停止、切换项目和关闭窗口先等待运行和相机操作完成再释放句柄；关闭窗口的第二次 Close 延迟到原 Closing 事件返回之后。运行结果 Dispose 可重复调用，相同对象的多个端口引用只释放一次。图像节点和区域节点的异常/取消路径补充释放，子图像窗口显式 Dispose 控件。

连接时设置可配置的 grab_timeout（默认 2000 毫秒，界面范围 100–60000）。参数单位与 HALCON 本机 24.11 采集文档一致；[MVTec MediaFoundation 官方接口文档](https://www.mvtec.com/fileadmin/Redaktion/mvtec.com/06_downloads/interfaces/hAcqMediaFoundation.html)也说明该参数用于等待图像的超时。

这套检查验证的是上述生命周期及输出所有权，不是所有相机驱动故障或长时间压力测试。
