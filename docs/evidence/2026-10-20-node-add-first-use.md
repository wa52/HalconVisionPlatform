# 首次添加节点无反应修复（2026-10-20）

## 复现与原因

实际查看用户窗口为“未打开项目”。原 `AddNode_Click` 在 `SelectedFlow == null` 时直接 return；节点库却一直显示“双击节点添加到当前流程”，没有项目/流程引导。不是 HALCON 匹配失败，也不是许可证问题。

最小回归 `HalconNodeAddTrial` 通过真实 WPF 添加按钮的 Click 路由调用生产处理器。在已存在空主流程但未选中当前流程时，修复前明确失败：`添加节点按钮应在空项目中建立流程并加入选中节点，而不是无反应`。修复后复用已有流程并添加，不覆盖项目。随后扩大到真实首次启动、取消、重试和全部节点类型。

## 修复

- 文件菜单和首次添加共享新建项目流程，不复制文件创建规则；项目路径选择作为可替换的显示层依赖，生产仍使用原系统保存窗口，自动检查使用隔离目录。
- 未打开项目时双击节点或点击添加，会选择新项目保存位置；成功后将原先选择的节点加入自动创建的主流程。保存取消后不写文件或添加节点，并提示如何重试。
- 已有项目优先使用当前流程；当前未选中时恢复已有首个流程，确实无流程才新建主流程。
- 未选中节点时有下一步说明。双击只处理命中的真实节点项，不在空白处重复添加先前选中项。
- 初始节点库说明改为“先保存项目，再加入主流程”，已有项目恢复原提示；仍只有一个可视添加入口，双击作为手势保留，图标及1.5秒提示机制不变。
