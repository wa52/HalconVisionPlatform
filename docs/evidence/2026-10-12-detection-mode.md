# 检测模式与节点输出

- 顶部“检测模式”开关将原图像控件扩展为主工作区，隐藏节点库、流程画布、属性与分隔条；退出恢复原编辑布局和面板可见性。
- 使用相同 HSmartWindowControl，切换模式不创建额外 HALCON 图像副本或显示窗口。
- 可以选择流程和节点，切换“图像 / 输出参数 / 检测结果”。检测模式连续运行保持当前显示节点。
- 编辑模式新增“节点输出”标签，展示实际序列化输出及对象子字段（直线坐标、角度、长度、评分、状态等）。数组显示数量，选择行可查看并复制完整 JSON；无结果显示“无结果”，未运行显示明确提示。
- 输出显示不持有 HALCON 运行时对象，重复运行和关闭仍由原生命周期管理释放资源。
- 检测模式屏蔽节点删除/复制粘贴编辑快捷键，输出表和详情文本仍支持正常复制。
