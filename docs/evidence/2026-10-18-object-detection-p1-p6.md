## 坐标与显示

读取本机官方 `dl_preprocessing.hdpl` 的 rectangle1 预处理实现：前向框缩放为 `(coord + 0.5) * factor - 0.5`；节点使用其逆变换，再加 ROI 原点。检查所有候选框在对应 ROI 的像素边界内。未执行独立标定样本的亚像素精度测量。

搜索框和目标框分别显示；错误类别保留为诊断数据，正常目标绿色，空结果/数量异常红色。真实 NG 类按配置前缀蓝色。当前 count 为逐 ROI 接受数之和，重叠 ROI 可能重复计数，不是全图去重物体数。

## 生命周期检查

以下检查全部通过：

1. 项目保存恢复完整保留六个 ROI 和连线。
2. 每张运行输出集中释放，原生对象 IsInitialized 为 false。
3. 启动前取消返回 Cancelled 且无运行输出。
4. 首张置信度阈值设为 1 后，六区均返回空目标和红色判定，不使用旧框。
5. 同一缓存模型恢复 0.5 后重新返回有效目标，modelInfo.cacheHit 为 true。
6. 错误期望类别导致执行失败，无旧检测输出；失败模型会话被移除。
7. 批处理结束缓存 Count=0。

本次不代表原生 GPU 调用中途取消、长时间内存/显存稳定性或真相机验收。当时训练平台另有 50 轮作业运行，耗时受并行 GPU 负载影响，不能作为部署性能基准；本轮去首张平均整链路约 3.42 秒/张。
