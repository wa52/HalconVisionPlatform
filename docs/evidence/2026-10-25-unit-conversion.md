# 等比例标定与毫米换算验收

起点 `2d7c16e`。只修改 HalconVisionPlatform，未修改用户原始方案、图片、模型、HALCON 安装或许可证。

## 实施范围

新增“比例标定”和“长度换算”两个职责独立节点。参考像素长度、标准毫米长度、参考宽高与条件确认保存在项目中；默认 0/未确认，不能输出可用比例。比例不从每张待检产品重新学习。换算保留像素值、毫米值、完整标定、单位和状态，不修改上游像素测量或另建预览图。

现有直线长度、圆直径/残差、圆圆、线圆和线线距离端口增加 `px` 声明，ID 与 `number` 类型不变。端口单位检查在设计时阻止角度、评分、面积、数量、已换算毫米或未知单位误接；运行时要求本轮同帧、同尺寸、同源、未标注且未矫正的空间。只有带单位的标量才额外保留帧来源。比例和换算对象亦保留帧身份。

首版是固定成像条件下的单一比例，不是镜头/透视标定。用户尚未提供标准件图片及实际尺寸，本轮只使用明确命名的合成演算方案。使用方法与实际限制见[标定说明](../PIXEL_MILLIMETER_CALIBRATION.md)。

## 合成链路与实际界面

HALCON 生成 512×384 两条亮条带，真实找线得到 150 px。演算标定设置 **100 px = 10 mm**，即 0.1 mm/px，换算得到 **15 mm**；毫米闭区间 [14.9,15.1] 为 OK。故意合法超差规则为 NG，空图为 ERROR，未确认标定阻断下游，均不使用旧数值或假零。完整[节点结果](unit-conversion-20261025/actual-result.json)保留参考参数和原始精度。

真实发布窗口操作：打开六节点检查副本 → 适应画布 → 移动标定分支 → 查看五项参数 → Ctrl+S 保存 → 单次 OK → 检测模式显示像素图形与毫米结果 → 第二次自动读空图，旧数值和图形消失，产品 ERROR。当前确认值和比例只存在于合成检查副本，未为用户真实方案填入演算比例。

## 限制

不能自动发现相同分辨率下的镜头/变焦/工作距离或物平面变化；条件变化必须重新标定。首版拒绝矫正图，不输出面积换算、非等比例映射和畸变补偿。真实标准件误差、全视场一致性、重复性、硬件相机/PLC 和 8 小时现场验收未完成。原间歇原生启动异常根因仍未确认，短时通过不证明该问题已解决。

实际正常/空图交替连续超过 100 秒后停止，再启动并在运行中关闭，本轮窗口已确认退出。其他发布路径及项目窗口保留。已备份到 artifacts/unit-conversion-desktop-backup-20261025 并同步原桌面路径；[六项发布哈希一致](unit-conversion-20261025/install-hashes.json)。未重新手工双击桌面入口，方案启动及恢复由真实窗口和生命周期检查覆盖。
