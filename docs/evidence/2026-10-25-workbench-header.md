# 顶部工作区去重与合并

根据用户实际截图反馈，原界面在系统标题栏之后叠放图标菜单、大标志和软件名称/副标题，再显示项目与产品状态；品牌信息重复，纵向层级过多。

## 调整

沿用 ui-ux-pro-max 的 WPF 布局与信息层次原则，将菜单、项目及产品状态、运行控制合并为一条顶部栏。移除工作区内部重复标志、软件名和副标题；系统标题、图标、程序及快捷方式名称保持不变。项目名伸缩并省略长内容，状态有最大宽度和完整提示，运行控制保留独立空间。检测模式收起菜单，保留项目、状态和运行入口，返回编辑后恢复菜单。

未新增操作入口；图标、键盘和 1500 ms 提示仍使用原共享实现。
