# 线圆测量

类型 `halcon.line-circle-measure`。连接同帧原始图像、直线查找的 `line` 和圆查找的 `circle`。单位为像素，公差复用检测任务中的数值范围规则。

## 距离含义

本节点使用 **两端点定义的无限直线**，不是有限线段距离。HALCON `distance_pl` 返回圆心到直线的垂距 d，半径为 r：

| 输出 | 含义 |
|---|---|
| `centerToLine` | 圆心到直线的非负垂距 d |
| `boundaryToLine` | 圆周到直线的最短距离 `max(0,d-r)` |
| `signedClearance` | 净距 `d-r`；负值表示直线穿过圆，不表示在线的哪一侧 |
| `measurement` | 完整直线、圆、垂足、垂足是否在线段内、距离、关系及测量线 |
| `overlay` / `preview` | 可组合几何与独立标注预览 |
| `status` | `LINE_CIRCLE_MEASURED` 或 `LINE_CIRCLE_MISSING` |

垂足超出拟合线段时，显示灰色延长线并提示该情况；垂足落到图像外则拒绝测量。相切或相交时圆周最短距离为零，不绘制假间隙。使用有限线段距离的工艺不能直接套用本节点。

## 显示和判定

基本属性只有“显示圆心垂线”和“显示圆周最短连线”。圆与拟合线为绿，圆心垂线青色，间隙线黄色。检测模式可组合图形、常用数值，净距在高级数据中可选；完整输出保持原精度，显示标注最多三位小数。

在检测任务添加数值范围规则，默认端口为 `boundaryToLine`，也可选择圆心垂距或净距。算法测量完成不等于产品 OK；正常测量但超差为 NG，必检几何缺失或异常为 ERROR。上下限包含边界，使用原始 double 比较。

## 输入与资源保护

只接收本轮同帧、同坐标空间、未标注的单张原图及几何。拒绝退化直线、越界圆、无来源或跨帧几何。测量所需直线、完整圆和垂足必须在有效图像域与绑定任务区域内；当前采用保守的包围矩形检查，不自动裁掉无效部分。

缺失几何输出空值，不回用旧 JSON、旧图形或假零值。预览使用独立图像副本，重跑及关闭由工作区结果生命周期释放。

本轮合成图和有限启停检查不替代毫米标定、标准件重复性、实物精度与长期现场验收。
