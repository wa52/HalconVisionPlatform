# 节点库布局调整（2026-11-09）

节点库的核心任务是快速找到并加入流程节点。保留现有工作台配色、名称和添加路径，将视觉重点放在分类及节点名称。

| 方案 | 判断 |
| --- | --- |
| 可折叠分类＋单列节点 | 采用。适合窄侧栏，完整保留名称，分类可直接扫描和收起。 |
| 分类导航＋独立节点列表 | 暂不采用。增加一次分类切换，窄侧栏内还要分配两块空间。 |
| 图标网格或卡片 | 暂不采用。长节点名容易截断，图标辨认成本高。 |

## 实现

- 按图像输入、图像处理、定位匹配、特征检测、几何测量、标定与单位、深度学习排序；测试节点置底并默认折叠。
- 分类标题显示节点数和折叠箭头；节点使用矢量语义图标、紧凑单行和左侧选中标记。
- 搜索名称、类别或说明，忽略首尾空白；匹配测试节点时自动展开。没有匹配时显示操作提示。
- 保留工具栏添加入口、双击手势、键盘选中及撤销重做。没有新增重复的添加按钮。
- 复用主题颜色与提示规则，中文说明延迟 1500ms；列表滚动条与工作台一致。
