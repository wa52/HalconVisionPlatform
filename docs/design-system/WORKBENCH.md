# 工程工作台界面规则

本轮使用本机 `ui-ux-pro-max` 的 WPF 指引，采用资源字典、键盘焦点和列表虚拟化建议。自动设计系统检索返回营销页 Hero/CTA 结构，与工程工作台不符，未采用其布局、网页字体及浅色调色板。以下为结合现有产品的具体设计决定。

## 场景和层次

工程师在左侧找节点，在中央编辑接线，在右侧配置参数，在底部检查图像及输出。检测模式以图像和必要结果为主要内容。沿用深色工作台和青绿色标识，避免切换主题影响既有工作习惯。

- 节点库按注册类别生成分组，搜索名称和类别；保留原双击及添加入口，不增加重复操作。
- 节点保留紧凑名称和端口，端口提示包含名称、输入输出方向和数据类型。
- 基础文字 12 px；类别/辅助信息 11 px；标题使用适度字重，状态使用既有语义色。
- 使用 Microsoft YaHei UI / Segoe UI 字体回退，启用布局取整。参数与结果保留文字，不用图标替代数据。

## 顶部结构（2026-10-25）

系统标题栏保留软件名称和图标；工作区不重复显示品牌。菜单、项目名、产品状态和运行控制合为单行，检测模式隐藏编辑菜单，项目名和状态保持可见。长项目名省略但保留完整提示。

## 资源和交互

共享资源位于 `src/HalconVision.App/Themes/Workbench.xaml`。

| 令牌 | 颜色 | 用途 |
|---|---|---|
| Surface | #1B2731 | 面板 |
| Raised | #24333F | 分区标题、悬停 |
| Input | #121B22 | 输入框 |
| Text | #E5EDF2 | 主文字 |
| Muted | #A4B4BF | 辅助文字 |
| Accent | #63D8CF | 分类和选中 |
| Focus | #91E6D5 | 键盘焦点 |

图标及中文提示继续遵循全局 1500 ms 延迟和跨控件 0 ms 规则。列表选中、悬停、键盘焦点分别反馈；搜索无结果提供说明。分组列表保持虚拟化和内容滚动。结果表最小行高 30、表头 32，省略文字可查看完整提示，节点输出仍有完整数据复制区。

图像常用标注按三位小数显示，这是工程显示选择，不是算法精度承诺；节点数据和公差计算保持原始 double。不得将格式化后的文字用于判定。

## 验证边界

真实窗口、最小和常用布局、搜索、模式切换、运行状态及结果检查记录于对应验收文档。多显示器、不同 DPI 和触摸未覆盖，不据此宣称全平台视觉验收。
