## 当前功能

- **项目**：新建空白 `.hvproj` 单文件项目，支持多个流程、保存和重新打开；双击关联的项目文件直接加载默认流程、节点、连线和参数。兼容旧版项目格式。
- **独立检测任务**：命名 ROI 与算法分支分离，一个区域可关联多个任务；任务设置必检/可选、节点成员和数值、文本、布尔或检测状态规则。统一产品判定中，缺结果、未完成、错误或不可信定位均不能成为 OK；配置变化使旧结论失效。含独立任务的方案保存为 schema 2，旧程序会拒绝不支持的版本。[配置及兼容边界](docs/INSPECTION_TASKS.md)
- **流程编辑**：节点库、紧凑节点、端口拖动连线、节点移动、复制、Delete 删除、撤销/重做、缩放、平移、流程校验和依赖顺序执行。
- **图像读取**：单张图片或文件夹序列；文件夹按文件名顺序读取，每次单次运行切换下一张。目录不递归扫描。
- **二值化与 Blob**：HALCON Threshold；RGB 图像先灰度转换。Blob 使用 Connection、SelectShape 和 CountObj。
- **快捷匹配**：HALCON 形状模板定位，支持选择模板图像或保存当前输入为模板，绘制模板/搜索矩形，配置评分、旋转和数量；输出参考点行列、角度、评分、匹配数组和明确的找到/未找到状态，连续运行复用模型，停止及关闭释放。[使用说明与边界](docs/QUICK_MATCH_NODE.md)
- **位置矫正**：接入同帧原始图像和快捷匹配位姿，示教后将单个产品的平移/旋转对齐到基准，输出矫正图、双向矩阵、偏移和有效区域，供固定 ROI 检测使用。无匹配、多匹配、过期基准及无效像素 ROI 明确阻断；原图与矫正图禁止跨空间误叠。[使用方法](docs/POSITION_CORRECTION_NODE.md) · [真实检查](docs/evidence/2026-10-19-position-correction.md)
- **直线查找**：在图像上绘制矩形搜索范围，配置方向、测量卡尺和边缘参数，通过 HALCON 2D Metrology 寻边并拟合直线。显示搜索矩形和延伸到矩形边界的拟合线，输出坐标、角度、长度、评分及 FOUND/NOT_FOUND 状态。
- **圆查找**：在矩形范围内按参考圆测量边缘，输出圆心、半径、直径、周长、评分、实际边缘点及 CIRCLE_FOUND/CIRCLE_NOT_FOUND；基本参数与折叠高级参数分开，完整圆和未找到状态明确显示。[操作与限制](docs/CIRCLE_FIND_NODE.md)
- **语义分割检测**：加载 HalconTrainingPlatform 导出的模型目录，使用保存的 preprocess.hdict 和官方 preprocess_dl_samples，执行 HALCON 深度学习推理。分割掩膜最近邻还原到原图尺寸并转为 byte，按类别和面积筛选区域，输出预览、掩膜、区域、数量、面积与对象坐标。支持 GPU/CPU 选择；已通过 NH320 模型 3 张真实图片的 GPU 推理和输出释放检查，准确率、CPU 及长期稳定性仍待验收。[验证记录](docs/evidence/semantic-inference-20261015.md)
- **多 ROI 裁剪推理**：语义分割和分类节点支持最多 64 个命名矩形，可新增、重绘、启用/禁用和删除，随项目保存。各 ROI 独立裁剪推理，分割结果映射回原图并保留独立掩膜，检测模式显示各区域结果；重叠区域分别统计。空列表使用全图，旧单 ROI 项目保持兼容。裁剪会改变模型输入内容，效果不保证与全图一致。
- **分类检测**：对接训练平台分类模型，通过 roiResults 输出各 ROI 的类别、置信度、全部类别评分及可配置的低置信度状态，支持原图叠加类别、置信度和 ROI。单 ROI 保留原标量端口；多 ROI 标量为空，避免误取某一区域代表全部。已完成真实分割/分类多 ROI 差分与 100 轮缓存回归，不代表产品准确率验收。[验收记录](docs/evidence/dl-roi-validation-20261016.md)
- **模型会话**：工作区内跨轮复用、默认最多两个模型；模型或设备变化使旧会话失效，停止、项目切换和关闭时清理。首次实际推理进行预热，冷启动仍单独计时。[生命周期约定](docs/DL_SESSION_LIFECYCLE.md)
- **目标检测**：接入 HALCON rectangle1 多类别模型，可绘制多个 ROI，输出原图检测框、类别、置信度、候选与接受目标、数量判定。期望类别填 `$roi` 按 ROI 名称匹配；置信度、NMS、数量和 NG 前缀可配置。P1～P6 已完成 12 张原图、72 个 ROI 的真实执行及有限生命周期检查；模型精度仍待独立验收。[实测记录](docs/evidence/2026-10-18-object-detection-p1-p6.md)
- **目标检测阈值**：选择目标检测节点，在右侧“节点属性 → 最低置信度（0–1）”中配置大于 0 且不大于 1 的数值。各节点独立设置，随项目保存，连续运行从下一轮生效。检测模式不显示阈值编辑控件。
- **相机采集**：选择本机可用的 HALCON 采集接口、扫描设备、连接/断开、连接预览。DirectShow 用于 Windows 摄像头；采集节点每次执行取一帧。
- **运行控制**：单次运行、连续运行和停止；连续执行支持文件夹回放及相机流程，防止重复启动。
- **图标操作**：运行、节点编辑、相机、ROI、图像工具、文件管理、显示配置与功能标签统一使用图标，鼠标停留 1.5 秒显示中文功能说明，切换控件仍需停留 1.5 秒。项目新建/打开/保存/导入/导出及文件选择同样图标化；节点名称、参数名称和检测数据保持可读。
- **操作入口**：项目文件操作集中在“文件”菜单，流程新建/导入/导出集中在“项目”菜单；单次/连续/停止只在顶部，节点添加/复制/粘贴/删除/撤销/重做和画布缩放只在流程工具栏。键盘快捷键与节点库双击添加仍可使用；各图像窗口保留独立的缩放操作。
- **自适应布局**：工具栏换行并自动调整高度；图像工具、标题和 ROI 绘制提示各占独立区域。长项目名省略显示并提供完整提示，侧栏保留最小操作宽度，多面板内容不足时可滚动查看。
- **图像交互**：适应窗口、缩放按钮、滚轮缩放和拖动平移；可查看节点输出图像。
- **检测模式**：只显示配置好的图像、检测框、判定及所选数据，顶部保留单次/连续/停止和返回编辑。面板管理、底图/节点选择、字段和高级坐标勾选移至编辑模式“视图 → 检测显示配置”；仍支持一张底图组合多个节点、多个面板和结果参数。图像支持滚轮缩放、左键拖动平移。
- **配置与资源**：底图、叠加节点和字段选择随项目保存；复制/导入流程重映射节点引用。HALCON 运行对象不写入项目文件，重跑、项目切换和关闭时集中释放。

## 使用方式

1. 新建或打开 `.hvproj` 项目，从节点库添加读取图像或相机采集节点。
2. 连接二值化、Blob、直线查找或快捷匹配节点，在属性区配置参数；直线查找先绘制矩形，快捷匹配先选择模板并设置模板范围。
3. 点击“单次运行”检查链路，使用“连续运行”和“停止”控制循环。
4. 在编辑模式“视图 → 检测显示配置”中选择底图、叠加节点与显示字段，再进入“检测模式”查看简洁的运行界面。
5. 保存项目。显示选择与算法参数一同保存在项目文件内。

深度学习节点的多 ROI 入口为“节点属性 → 多 ROI 检测范围 → 新增 ROI”，随后在节点图像区拖动绘制。检测模式选择 mask 端口时，可切换各 ROI 的掩膜；检测结果/输出参数提供 roiResults 明细。列表非空且全部禁用会报错，清空列表才表示全图推理。

分类结果的 ROI 框线、标注及判定摘要采用以下规则；原始类别、置信度和全部评分仍保留：

| 分类输出 | 颜色与标注 |
| --- | --- |
| 达到最低置信度的普通类 | 绿色 OK |
| 低于最低置信度，未接受该分类 | 红色 NG · 未检出 |
| 达到最低置信度，类别以 NG 前缀开头 | 蓝色 · 检出 NG |

“NG 类别前缀”默认 `NG`，在分类节点属性中可修改，不区分大小写。低置信度优先标红，即使最高评分来自 NG 类也不会标成已检出。`decision` 输出总体判定和数量，`roiResults[].Decision` 输出逐区域判定；混合结果的摘要优先显示红色未检出，其次蓝色检出 NG，全部普通类时绿色。分类是对裁图的类别判断，红色“未检出”表示没有接受分类结果，不表示模型具有目标定位或空图检测能力。运行错误保留独立错误状态。

语义分割链路为“读取图像/相机采集 → 语义分割检测”。在属性区选择训练模型目录，设置目标/背景类别 ID 及面积条件；检测模式中可在原图上叠加分割区域轮廓。详见 [语义分割节点](docs/SEMANTIC_SEGMENTATION_NODE.md)。

## 构建与部署

要求 Windows x64、.NET 8 SDK 和本机 HALCON 24.11 x64 运行环境。MVTec 包版本为 `24111.0.0`。

```powershell
dotnet build src/HalconVision.App/HalconVision.App.csproj -c Release
dotnet run --project src/HalconVision.App/HalconVision.App.csproj
```

发布并更新桌面快捷方式及 `.hvproj` 文件关联：

```powershell
dotnet publish src/HalconVision.App/HalconVision.App.csproj -c Release -m:1 -o artifacts/publish
powershell -NoProfile -File tools/InstallDesktop.ps1 -PublishedDirectory artifacts/publish
```

脚本默认安装到 `artifacts/desktop`；也可显式指定项目 artifacts 下的安装目录。更新后关闭旧版本，再通过快捷方式或项目文件启动。脚本不覆盖 Windows 受保护的默认应用选择；必要时在“打开方式”中手动选择本平台。

## 验证与边界

已完成独立 HALCON 算子调用、真实图片直线查找、WPF 显示及生命周期回归。2026-10-12 同图叠加版本通过 47 项真实图片检查和 39 项生命周期检查；包含 200 次执行释放 400 个旧图像/区域、连续刷新、反复启停和关闭清理。2026-10-13 文档同步了后续的常用/高级字段调整；这次文档更新未重新运行测试。

2026-10-16 增加真实多 ROI 与分类检查，缓存版本 100 轮共 1425 项断言通过，重新通过 39 项原有生命周期回归，并修复绘制后 ROI 框消失、运行后切换检测模式黑屏和同位结果文字重叠。短期数据见 [多 ROI 验收](docs/evidence/dl-roi-validation-20261016.md)，不替代长时间显存/稳定性及准确率验收。

相机生命周期回归使用 HALCON 官方 File 采集接口，不能替代真实物理相机及驱动验收。相机可用性取决于本机接口、驱动、设备占用和配置。PLC/IO、自定义 HDevelop 程序导入、生产追溯、权限和长时间产线验收尚未完成。语义分割内部使用 HDevEngine 执行官方预处理，当前只支持 full_domain。未注入工作区缓存的独立执行器仍逐轮加载并清理模型。

图像路径仍为本机路径。叠加图形要求本轮同帧、同坐标空间及匹配尺寸；深度学习节点内部 ROI 映射到其输入图像坐标。位置矫正建立独立的基准空间，下游固定 ROI 在矫正图中检测，双向矩阵保留，但尚不自动回投下游结果到原图。通用裁剪/缩放/透视节点未实现。找到/未找到、分类结果与执行成功是不同状态，结果应结合实际样品和参数判断。

2026-10-19 位置矫正最终核心/生命周期 518 项、快捷匹配回归 197 项、布局 113 项通过，并在真实 WPF 中完成示教、旋转图运行、保存和检测模式检查。另用既有 HALCON 目标检测模型对一张产品及其派生偏移图执行 P1～P6，均为 4 个 OK、2 个未检出；这是链路检查，不代表精度或长期产线验收。
